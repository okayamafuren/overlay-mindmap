📝 노드 조작

  • 노드 추가: 툴바의 "+" 버튼 또는 A 키
  • 노드 선택: 노드 클릭 (다중 선택: Shift+클릭)
  • 노드 드래그: 노드를 클릭하고 이동
  • 노드 크기 조절: S 키를 누른 상태에서 노드를 드래그 (Blender 스타일)
  • 텍스트 편집: 노드 텍스트 영역 더블클릭 (인라인 편집)
  • 속성 편집: 노드 텍스트 외 영역 더블클릭 또는 선택 후 속성 패널에서 편집
  • 노드 삭제: 노드 선택 후 Delete 또는 Backspace 키

🔗 연결하기

  • 연결 모드: 툴바의 "●" 버튼 또는 C 키
  • 연결 방법: 첫 번째 노드를 클릭한 후 두 번째 노드를 클릭
  • 연속 연결: 툴바에서 시작한 연결 모드는 여러 노드를 연속으로 연결 가능
  • 우클릭 연결: 노드 우클릭 → 연결 버튼 (한 번만 연결 후 종료)
  • 연결선 스타일: 연결선 선택 후 속성 패널에서 변경 (실선/점선/굵은 선)

🎨 노드 스타일링

  • 우클릭 메뉴: 노드 우클릭으로 색상, 모양, 선 스타일, 테두리 변경
  • 색상: 🎨 버튼으로 8가지 색상 선택
  • 모양: ⭕ 버튼으로 원형/사각형/다이아몬드/육각형 선택
  • 테두리: 🔲 버튼으로 테두리 두께 조절 (얇음/보통/굵음/없음)
  • 속성 패널: 노드 선택 후 속성 패널에서 색상, 크기, 폰트, 투명도, 아이콘, 메모, 태그, 우선순위, 진행률, 링크 등 상세 설정

🖼️ 이미지 노드

  • 이미지 추가: 노드 선택 → 속성 패널 → "이미지 불러오기"
  • 이미지 표시: 이미지가 있는 노드는 노드 형태 없이 이미지만 표시
  • 이미지 비율 조절: 속성 패널에서 가로세로 비율 슬라이더로 조절 (0.1 ~ 3.0)
  • 이미지 제거: 속성 패널 → "이미지 제거"
  • 기능 유지: 이미지 노드도 연결, 크기 조절, 드래그 등 모든 기능 사용 가능

🔍 줌 & 팬

  • 줌 인/아웃: 마우스 휠 또는 +/- 키
  • 줌 리셋: 0 키로 100%로 복원
  • 팬: 중간 버튼 드래그 또는 Ctrl+왼쪽 버튼 드래그
  • 맞춤: 툴바의 "⌂" 버튼 또는 F 키 (모든 노드가 화면에 맞게)
  • 방향키 이동: ↑↓←→ 키로 캔버스 이동

📐 정렬 기능

  • 정렬 메뉴: 툴바의 정렬 버튼 클릭
  • 정렬 옵션: 왼쪽/오른쪽/위/아래/수평/수직 정렬
  • 단축키: Ctrl+Shift+L (왼쪽), Ctrl+Shift+R (오른쪽), Ctrl+Shift+T (위), Ctrl+Shift+B (아래), Ctrl+Shift+H (수평), Ctrl+Shift+V (수직)
  • 조건: 2개 이상의 노드가 선택되어 있어야 함

🔎 검색

  • 검색: 툴바의 검색창에 키워드 입력
  • 검색 결과: 검색 결과가 표시되면 클릭하여 해당 노드로 이동
  • 검색 취소: 검색창 비우기

⚙️ 보드 설정

  • 보드 색상: 툴바의 보드 색상 버튼으로 변경 (검은색/흰색/투명)
  • 그리드 표시: 툴바의 "#" 버튼으로 그리드 표시/숨김 또는 G 키

⌨️ 단축키

  • A: 노드 추가
  • C: 연결 모드 토글
  • F: 화면에 맞춤
  • G: 그리드 표시/숨김
  • M: 암기 모드 토글
  • P: 마우스 통과 모드 (다른 앱 사용 가능)
  • S: 크기 조절 모드 (누른 상태에서 드래그)
  • ?: 도움말 표시/숨기기
  • +/-: 줌 인/아웃
  • 0: 줌 리셋 (100%)
  • ↑↓←→: 캔버스 이동
  • Delete/Backspace: 선택된 노드 삭제
  • Escape: 연결 모드 종료 또는 앱 종료
  • F11: 전체화면 토글
  • Ctrl+Z: 실행 취소
  • Ctrl+Y 또는 Ctrl+Shift+Z: 다시 실행
  • Ctrl+S: 파일 저장
  • Ctrl+O: 파일 열기
  • Ctrl+C: 선택된 노드 복사
  • Ctrl+V: 노드 붙여넣기
  • Ctrl+A: 전체 노드 선택
  • Ctrl+Shift+L: 왼쪽 정렬
  • Ctrl+Shift+R: 오른쪽 정렬
  • Ctrl+Shift+T: 위 정렬
  • Ctrl+Shift+B: 아래 정렬
  • Ctrl+Shift+H: 수평 정렬
  • Ctrl+Shift+V: 수직 정렬

💾 파일 관리

  • 저장: Ctrl+S 또는 툴바의 저장 버튼
  • 열기: Ctrl+O 또는 툴바의 열기 버튼
  • 자동 저장: 작업 내용이 자동으로 임시 파일에 저장됨
  • 최근 파일: 프로그램 시작 시 최근 파일 자동 로드

🎯 특수 기능

  • 암기 모드: M 키로 토글, 노드 텍스트를 숨겨 암기 연습
  • 마우스 통과 모드: P 키로 토글, 마인드맵 뒤의 다른 앱 사용 가능
  • 전체화면: F11 키 또는 툴바의 전체화면 버튼
  • 최소화: 툴바의 "_" 버튼

📋 패널 조작

  • 패널 이동: 패널 헤더를 드래그하여 위치 변경
  • 패널 확장/축소: 패널 헤더의 "⛶" 버튼 클릭
  • 패널 닫기: 패널 헤더의 "✕" 버튼 클릭
  • 속성 패널: 노드 선택 시 자동으로 열림
  • 도움말 패널: ? 키 또는 툴바의 "?" 버튼

💡 팁

  • 노드 텍스트 영역을 더블클릭하면 인라인 편집이 시작됩니다
  • 노드 텍스트 외 영역을 더블클릭하면 속성 패널이 열립니다
  • S 키를 누른 상태에서 드래그하면 노드 크기를 조절할 수 있습니다
  • 우클릭 메뉴에서 노드 스타일을 빠르게 변경할 수 있습니다
  • 이미지 노드는 노드 형태 없이 이미지만 표시되지만 모든 기능을 사용할 수 있습니다
  • 연결 모드는 툴바에서 시작하면 연속 연결이 가능하고, 우클릭에서 시작하면 한 번만 연결됩니다
